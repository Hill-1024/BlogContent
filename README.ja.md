# BlogContent

[中文](./README.md) | [English](./README.en.md) | 日本語

BlogContent は個人ブログのコンテンツリポジトリです。記事、特別ページ、画像素材、サイト資料をブログテーマやサイトコードから分離して保存し、内容を独立して管理、同期、移行できるようにします。

このリポジトリはブログのフロントエンドをビルドしません。コンテンツソースとして、テーマプロジェクトがここにある Markdown、画像、ページデータを読み込み、最終的なサイトを生成します。

## 内容範囲

- ブログ記事とチュートリアル。
- プロジェクト記録と授業課題資料。
- CTF write-up、プロキシ構築、Markdown 例などの技術内容。
- デバイス、日記、アルバム、プロジェクト画像。
- About、Friends などの特別ページ。

## 構成

```text
.
├── avatar.jpg
├── posts/
│   ├── *.md
│   └── <post-name>/
│       ├── index.md
│       └── assets
├── images/
│   ├── albums/
│   ├── device/
│   ├── diary/
│   └── projects/
├── spec/
│   ├── about.md
│   └── friends.md
└── data/
```

| Path | 説明 |
| --- | --- |
| `posts/` | ブログ記事。単一ファイル記事とディレクトリ型記事に対応 |
| `images/` | サイト画像素材 |
| `spec/` | About、Friends などの特別ページ |
| `data/` | テーマが読み取る構造化コンテンツ |
| `avatar.jpg` | サイトアバター |

## 記事形式

記事は frontmatter 付き Markdown です。

```yaml
---
title: 記事タイトル
published: 2026-01-01
description: 記事概要
image: ./cover.png
tags: [Tutorial, Project]
category: Category
alias: "optional-alias"
draft: false
---
```

よく使うフィールド：

| Field | 説明 |
| --- | --- |
| `title` | 記事タイトル |
| `published` | 公開日 |
| `description` | 一覧と SEO 用の概要 |
| `image` | カバー画像 |
| `tags` | タグ配列 |
| `category` | カテゴリ |
| `alias` | 検索またはルーティング用エイリアス |
| `draft` | 下書きかどうか |
| `pinned` | 固定表示するかどうか |

## 執筆ルール

- 長い記事は `posts/name/index.md` のようなディレクトリ型にし、画像を記事と同じディレクトリに置くことを推奨します。
- 再利用する画像は `images/` に置き、リポジトリルートへ散らさないでください。
- 未完成の記事は `draft: true` を設定してください。
- チュートリアルでは、環境、バージョン、コマンド、トラブルシューティングをできるだけ残します。
- アカウント、IP、キー、サーバーアドレスはコミット前にマスクしてください。

## サイトプロジェクトとの関係

ブログサイトまたはテーマプロジェクトは、このリポジトリをコンテンツソースとして `src/content`、`posts`、または同等のディレクトリへ同期できます。このリポジトリはコンテンツ構造と素材に集中し、特定のビルドフレームワークには固定されません。

## ライセンス

このリポジトリでは統一ライセンスをまだ明示していません。記事、画像、個人素材は既定で作者が権利を保持します。転載や再利用の前に作者へ連絡してください。
